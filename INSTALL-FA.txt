VapePad Market - راهنمای نصب

محتویات:
- index.html
- style.css
- app.js
- supabase-migration.sql

مراحل:
1) ابتدا از مخزن GitHub فعلی یک نسخه پشتیبان بگیر.
2) سه فایل index.html، style.css و app.js را در ریشه مخزن (main / root) جایگزین کن.
3) در Supabase > SQL Editor فایل supabase-migration.sql را اجرا کن.
4) سایت GitHub Pages را باز کن و یک بار Ctrl+F5 بزن.

نکات مهم:
- آدرس Supabase، کلید Publishable و شناسه مدیر از تنظیمات موجود پروژه قبلی حفظ شده‌اند.
- این نسخه از جدول vm_products و vm_orders فعلی استفاده می‌کند.
- سیستم تیکت به جدول support_tickets نیاز دارد؛ SQL آن را می‌سازد.
- برای موجودی امن، قیمت/تخفیف سمت سرور و ذخیره روش ارسال و تست دستگاه، باید Edge Function فعلی create-order نیز به‌روزرسانی شود. این سه فایل به‌تنهایی نمی‌توانند منطق سمت سرور را تغییر دهند.
- کد درگاه پرداخت فعلی عمداً بازنویسی نشده؛ تا زمان تأیید نکست‌پی، منطق موجود در Edge Function خود را حفظ کن.
- اگر نام ستون‌های جدول vm_orders یا ساختار Edge Function فعلی متفاوت باشد، باید آن فایل تابع هم بررسی و اصلاح شود.
- هرگز کلید service_role را داخل app.js قرار نده.
