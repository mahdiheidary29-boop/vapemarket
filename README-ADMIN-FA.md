راهنمای نسخه اصلاح‌شده پنل مدیریت Vape Market

۱) این بسته شامل index.html، style.css و app.js است. در GitHub هر سه فایل را در پوشه اصلی (root) جایگزین کنید و Commit changes بزنید. ZIP را به‌تنهایی به‌عنوان جایگزین فایل‌های سایت آپلود نکنید؛ ابتدا آن را استخراج کنید.

۲) شناسه مدیر از قبل در app.js تنظیم شده است. این شناسه از حسابی گرفته شده که در Supabase ساخته‌اید.

۳) برای ورود مدیر به سایت، دکمه حساب کاربری را باز کنید و با همان ایمیل و رمزی که هنگام ساخت کاربر در Supabase وارد کردید، وارد شوید. در حالت ورود، فیلد اول ایمیل یا شماره تلفن می‌پذیرد. ثبت‌نام مشتریان همچنان با شماره تلفن و رمز انجام می‌شود.

۴) کلید Publishable داخل app.js کلید عمومی قابل استفاده در مرورگر است. هرگز کلید Service Role را در سایت قرار ندهید.

محدودیت امنیتی مهم:
این نسخه فقط پنل سمت مرورگر را بر اساس UID محدود می‌کند. چون محصولات فعلاً در localStorage ذخیره می‌شوند، این تغییرات برای همه کاربران مشترک نیستند و قفل سمت مرورگر جایگزین امنیت سمت سرور نیست. برای امنیت واقعی و محصولات مشترک باید داده‌ها به جدول Supabase منتقل شوند و RLS/policies سمت سرور تنظیم شوند.
